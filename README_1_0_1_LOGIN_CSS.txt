ServusPBX Medical 1.0.1 - Login + CSS

Installation:
1. Dateien nach /var/www/html kopieren.
2. Datenbank SQL vorher importieren.
3. /set_admin_password.php öffnen und Admin-Passwort setzen.
4. set_admin_password.php danach löschen.
5. Login über /login.php

Login-Logik:
- role=admin -> Admin-Dashboard
- role=user  -> User-Dashboard / eingeschränkte Oberfläche
